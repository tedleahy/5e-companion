Shared interaction model

All variants below use the same data & detail panel. Default to collapsed (current level only / peek). Expand to pick another level. Prefill toast when advancing +1. Fill-remaining is a dashed action under the editor.

Try: collapse → expand → tap a distant level → edit slots → advance with −/+ in the detail header (where present) or by picking the next cell.

D1 · Accordion cell

Collapsed: current level tile + short summary (grid hidden). Expand: full 5×4 map. Most aggressive space save — picking a level auto-collapses again.
