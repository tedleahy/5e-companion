B · By category

Fixed + choice coexist
Each category has Always granted chips and an optional separate pick-N pool. Toggling choice on does not convert or clear the grants — Artificer tools need both.
Three natural states
Granted only (armor), Choice only (skills), Both (tools). Header summary + badges reflect which are active.
Tools is the showcase
Starting Tools mocks Artificer: Thieves’ + Tinker’s granted, choose 1 artisan tool. Multiclass Tools mocks Bard-style instrument pick.
Still open
Multiple independent choice groups within one type (choose 2 skills and choose 1 tool-from-another-list) may still need “+ Add another choice”. Prereqs on Multiclass tab vs third tab.
